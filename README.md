# BirdsEye Calendar

A desktop-first annual calendar prototype inspired by the “Year at a Glance” spreadsheet format. It keeps all twelve months visible in one scan-friendly grid while adding filters, search, density controls, and daily agenda details.

## Run locally

```bash
npm install
npm run dev
```

The first prototype uses deterministic demo data. Google Calendar OAuth and sync are intentionally left behind a clear integration boundary for the next build step.
